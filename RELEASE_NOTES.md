## v0.23.3-beta

### Novidades

- **O app abre direto, sem senha nem código por convite**: o sistema de trava de acesso foi totalmente removido. Não existe mais tela de bloqueio, código de convite nem consulta na internet para liberar o app — quem instalar esta versão entra direto no TuneGrab.
- O tutorial de primeira abertura e todas as funções continuam funcionando como antes.

### Sobre a versão

- O app se identifica como 0.23.3-beta (código 102).
- A beta continua podendo ser instalada ao lado da versão estável (ID de aplicativo diferente).
- Esta é uma versão BETA e pode conter bugs ou comportamentos inesperados. Para reportar problemas, use o rastreador de issues do repositório.
