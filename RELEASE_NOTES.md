## v0.23.0-beta

### Novidades

**Busca Integrada - Abriga músicas do YouTube sem copiar links!**

- Nova aba "Busca" na barra de navegação inferior
- Digite o nome da música ou artista e encontre vídeos instantaneamente
- Resultados com thumbnails, títulos e canais
- Botão de download direto — tudo integrado ao fluxo de downloads do TuneGrab
- **Nenhuma chave de API necessária** — usa o mesmo mecanismo do NewPipeExtractor usado para downloads

### Outras melhorias

- **Application ID alterada:** `com.tunegrab.app.beta`
- Agora você pode instalar a versão beta ao lado da versão estável
- Versão testável para desenvolvimento e feedback

### Aviso importante

Esta é uma versão BETA. Pode conter bugs ou comportamentos inesperados.
Para reportar problemas, use o rastreador de issues do repositório.

---

## Como usar a versão beta

1. Instale o APK baixado desta release
2. A versão beta tem um ID diferente da estável, então ambas podem coexistir
3. Para atualizar para a versão estável, desinstale a beta e instale a release mais recente
